2. **레슨 할인 차등:** SILVER 10% / GOLD 5%라는 역전 정책이 의도된 것인지 확인. 적용 대상이 박형규 프로 월 30만 원 레슨인지, 다른 프로그램인지를 구분.
3. **GOLD/PREMIUM 가용:** 대표가 ‘가능/사용 가능’이라고 안내. 이는 사이트에서 자동 가입·정기결제를 할 수 있다는 의미가 아님. 실제 수동 가입 절차·계약서·혜택 시작일을 대표가 확정해야 함.
4. **VIP 무제한 점검:** 점검 종류, 정상 범위, 예약·영업시간, 소모품·공임 유료 여부, 이용 기준 및 과도 사용 제한을 계약서로 확정해야 함.
5. **환불·해지:** 멤버십의 월 과금 시작/해지 시점/잔여기간 정산 기준을 소비자 법령과 결제사 조건에 맞춰 확인.
