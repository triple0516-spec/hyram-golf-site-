- **상담 확정:** "HYRAM GOLF 상담 일정이 [날짜] [시간]으로 확정되었습니다. 준비사항: 사용 중인 클럽 사진 또는 스펙 메모입니다." (실제 예약 확정 후에만 발송)

## 4순위 · 상담/회원 운영 시트
`docs/templates/` CSV에는 **헤더만** 포함. 고객 실명/연락처는 공개 저장소에 기록하지 말고 내부 권한 제어가 있는 저장소에서 관리한다.
- `members.csv`: 회원번호, 이름, 연락처, 카카오ID, 멤버십등급, 가입일, 다음결제일, 상태
- `consultations.csv`: 회원번호, 상담일자, 유형, 요약, 추천클럽, 비고
- `club-care.csv`: 회원번호, 일자, 내용, 상세
- `reservations.csv`: 회원번호, 일자, 시간, 유형, 상태

### 개인정보·코드 보안 차단
업로드 파일의 Apps Script `searchMember(name, phone)`는 이름/연락처 일치만으로 상담·구매 내역을 제공하므로 안전한 인증이 아니다. `ALLOWALL` 임베드와 사용자 텍스트를 `innerHTML`에 직접 연결하는 코드도 보안 위험이 있어 **그대로 배포하지 않는다**. 앱 로그인/회원가입과 별개로 서버에서 인증·인가를 보장할 때만 구현할 것.
