# HYRAM GOLF 실제 결제 출시 게이트 (2026-10-08)

상태: **BLOCKED — 실제 결제 비활성화**. GitHub Pages는 정적 호스팅이므로 토스페이먼츠 비밀키를 보관하거나 결제 승인 API를 안전하게 호출할 수 없다.

## 필수 준비
1. 토스페이먼츠 상점 계약/심사 완료, 상점 전용 테스트 키 및 라이브 키 발급. 라이브 시크릿 키는 채팅·GitHub·브라우저에 절대 넣지 않는다.
2. 서버 호스팅 및 데이터베이스 준비: 서버 환경변수/시크릿 저장소에 키 보관. 주문·금액·상태·결제키·취소내역 영속 저장.
3. 서버가 상품별 확정 판매가를 계산한다. 동일 사양 검증 기준가 20% 할인, 커스텀 추가금(드라이버 130,000 / 아이언 170,000 / 우드·유틸 100,000 / 지정 프리미엄 300,000 또는 개별 견적)을 적용한다. 클라이언트 전달 금액을 신뢰하지 않는다.
4. POST /api/orders: 서버에서 금액/재고/샤프트·인치/고객정보 검증 후 주문번호 발급. 미확정 견적 상품은 결제 불가.
5. 토스 SDK v2에서 결제 요청 후 successUrl로 돌아오면 서버에서 주문번호·금액을 검증하고 POST /v1/payments/confirm 호출. 중복 승인 방지, 인증, 접근 통제, 감사 로그 필요.
6. 결제 실패/중단, 중복 요청, 금액 변조, 결제 승인 지연, 전체/부분 취소, 웹훅, 재고 차감·복구, 개인정보 보관·삭제 검증.
7. 멤버십 정기결제는 일반 1회 결제와 별개. 빌링키 발급, 갱신·해지·환불·실패 재시도·고객 고지, 별도 계약 및 약관 검증 전 자동청구 금지.
8. 테스트 결제/취소 PASS → 실제 MID/라이브 키 검증 → 소액 실결제/취소 PASS → 출시 승인 → main 병합/배포.

## 고정 규칙
- 실제 결제와 자동갱신을 검증하기 전에는 고객에게 '결제 완료'라고 표시하지 않는다.
- 서버나 라이브 키가 없으면 결제 버튼을 활성화하지 않는다.
- 제품 사진·재고·가격 미확정 상품은 상담만 가능하다.
